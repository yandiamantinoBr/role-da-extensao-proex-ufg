# Fonte dos relatórios PDF

Noto Sans Regular, distribuída com licença SIL Open Font License 1.1 (arquivo `OFL.txt`). Download em 31/10/2026 do repositório oficial arquivado do projeto Noto:

https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

SHA-256 do arquivo original: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

A aplicação serve esta fonte na própria origem e incorpora apenas os glifos usados no PDF. Não envia os dados do relatório a um serviço de conversão externo. Símbolos ausentes da fonte são preservados por código Unicode legível, como `[U+1F600]`.
