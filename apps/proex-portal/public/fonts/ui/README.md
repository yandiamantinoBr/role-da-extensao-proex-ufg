# Fontes da interface

- **DM Sans** (texto, pesos 400 a 700) e **Sora** (títulos e números, pesos 600 a 800).
- Licença SIL Open Font License 1.1 (`DM-Sans-OFL.txt`, `Sora-OFL.txt`).
- Origem: Google Fonts (`https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Sora:wght@600..800`), subconjuntos `latin` e `latin-ext`, os mesmos arquivos usados nas peças do Rolê da Extensão.
- Servidas pela própria origem do portal: nenhuma chamada a serviço externo de fontes.
- Para trocar a tipografia, altere apenas `--font-sans` e `--font-display` no fim de `app/globals.css`.

Os relatórios em PDF continuam usando Noto Sans (`../NotoSans-Regular.ttf`).
